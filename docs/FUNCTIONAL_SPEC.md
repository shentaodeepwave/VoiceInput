# 迷你语音输入助手 - 功能需求文档

## 1. 窗口外观
- 设计一个**黑色半透明简约卡片样式**窗口。
- 尺寸：`400 x 250` 像素。
- 窗口**始终置顶**（Always on Top）。
- 窗口**可拖动**（通过标题栏或任意空白区域）。

## 2. 界面元素
- **麦克风按钮**：位于窗口右下角，迷你绿色按钮。  
  *（窗口内无其他额外按键）*
- **内部文本框**：窗口内有一个**只读或可编辑**的小文本框（高度约 60px），用于实时显示识别结果（与光标所在输入框同步追加），用户可选中复制。
- **托盘图标**：程序运行时在系统托盘显示小图标。
- **设置面板**：通过托盘菜单中的“设置”打开（而非窗口内直接放置齿轮图标）。

## 3. 录音控制

### 3.1 触发方式
- **鼠标单击**麦克风按钮 → 开始录音 / 停止录音（切换）。
- **全局快捷键**（默认 `Fn`，用户可自定义） → 与鼠标单击行为完全一致。

### 3.2 录音状态
- **空闲**：麦克风按钮为**绿色**迷你图标。
- **录音中**：按钮变为**红色**，并变换图标（例如麦克风变成方块），同时提示用户正在录制。

### 3.3 录音逻辑
- 录音过程中，**实时将音频分片发送**到语音识别 API，并**实时接收识别结果**。
- 识别结果**不断追加**到：
  1. **当前光标所在的输入框**（实现实时打字效果）。
  2. **窗口内部的文本框**（防止光标不在任何输入框内时丢失文字，用户可选中复制）。
- 停止录音后，不再发送新分片，但**等待最后几秒的结果返回并追加**。
- 若录音时长 **< 0.5 秒**，则忽略本次录音，不调用 API，不追加文字。
- 录音时长上限：不限（或由 API 限制），但建议前端做 60 秒自动停止。

### 3.4 错误处理
- 如果 API 返回中间结果出错或网络中断：
  - 立即停止录音。
  - 窗口内部文本框显示“识别中断”。
  - 不追加错误信息到光标输入框。

## 4. 全局快捷键与唤醒
- 默认快捷键为 `Fn`（用户可在设置中自定义）。
- **按全局快捷键**的行为：
  - 如果窗口未隐藏：开始录音 / 停止录音（同鼠标单击）。
  - 如果窗口已最小化到托盘：**先重新唤起窗口，然后自动开始录音**。
- 窗口右上角应提供**最小化到托盘图标**（`_`）和**关闭程序图标**（`✖`）。

## 5. 系统托盘行为
- 程序正常运行后，系统托盘显示程序图标。
- 托盘图标**右键菜单**包含两个选项：
  - **设置**：打开设置面板。
  - **关闭程序**：完全退出程序。
- 托盘图标左键单击（可选）：建议行为为显示主窗口（若已隐藏），不直接开始录音。

## 6. 首次启动 & 麦克风权限
- 首次启动时，自动弹窗请求麦克风权限。
- 弹窗提供“允许”和“拒绝”选项：
  - **允许**：获取权限，正常使用所有录音功能。
  - **拒绝**：无法使用录音功能，麦克风按钮禁用或提示无权限。
- 拒绝后，用户可通过设置面板中的“重新授权麦克风权限”按钮重新请求。

## 7. 设置面板（通过托盘菜单打开）

设置面板应包含以下控件：

### a. 重新授权麦克风权限按钮
- 点击后重新请求系统麦克风权限。

### b. 录音模式切换
- **长按/点按模式**：
  - 默认 **点按模式**：单击麦克风按钮或快捷键开始录音，再次单击停止。
  - 可选 **长按模式**：按住麦克风按钮（或快捷键）时录音，松开立即停止。

### c. 自定义全局快捷键
- 允许用户自定义全局快捷键（如 `Ctrl+Shift+R`、`Alt+V` 等）。
- 需提供输入框和保存按钮，修改后立即生效。

### d. 静音检测（VAD）
- **开关**：启用/禁用 VAD。
- **静音时长输入框**：支持用户随意输入数字（单位秒），例如 `0.5`、`2`、`5` 等。
- 启用 VAD 后，录音过程中若检测到静音持续时间超过设定值，**自动停止录音**（等价于手动停止）。

### e. API 配置
- **API 地址输入框**：提供默认示例（如 `https://api.xfyun.cn/v1/...`）。
- **API Key / 密钥输入框**：用于用户填写自己的凭证。
- 可选：提供一个“测试连接”按钮，用于验证 API 配置是否正确。

## 8. 关闭行为
- 点击窗口右上角的 **关闭图标（✖）** → **完全退出程序**（不保留托盘图标）。
- 退出前若正在录音，应先停止录音并丢弃当前音频（不调用 API）。

## 9. 非功能性要求（建议）
- 内存占用：空闲 < 50MB，录音时 < 100MB。
- CPU 占用：动画（音量波动）运行时 < 10%。
- 支持平台：Windows 10/11（若使用 Electron 可跨平台）。
- 流式识别需使用 WebSocket 或 Server-Sent Events 实现真实分片传输，不可简单用 setTimeout 模拟。
