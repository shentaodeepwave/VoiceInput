# 迷你语音输入助手 - 交互逻辑文档

## 1. 状态定义

| 状态 | 英文标识 | 说明 |
|------|----------|------|
| 空闲 | `idle` | 未录音，麦克风按钮为绿色，等待用户操作 |
| 请求权限中 | `requesting` | 首次启动或重新授权时，系统权限弹窗未返回 |
| 录音中 | `recording` | 正在采集音频，按钮红色，实时发送分片 |
| 识别中 | `recognizing` | 停止录音后，等待最后几秒识别结果返回 |
| 错误 | `error` | 无麦克风权限、API 失败、网络中断等 |
| 隐藏（托盘） | `hidden` | 窗口最小化到托盘，后台运行 |

## 2. 用户操作与系统响应

### 2.1 全局触发方式（鼠标单击麦克风按钮 或 全局快捷键）

| 当前状态 | 操作 | 系统响应 | 下一状态 |
|----------|------|----------|----------|
| `idle` | 单击/快捷键 | 请求麦克风权限（若已有则直接开始录音）→ 开始采集音频分片 → 启动流式识别 → 按钮变红 → 窗口文本框清空旧内容（可选） → 光标所在输入框实时接收文字 | `recording` |
| `recording` | 单击/快捷键 | 停止音频采集 → 不再发送新分片 → 等待最后几秒结果 → 状态文字变为“识别中” | `recognizing` |
| `recognizing` | 单击/快捷键 | 忽略（或立即停止等待并清空本次结果）→ 建议：不做响应，或提示“请等待识别完成” | `recognizing` |
| `error` | 单击/快捷键 | 如果错误原因为“无权限”，提示重新授权；否则尝试恢复（重新请求权限或重试） → 成功则回到 `idle` 后开始录音 | `recording` 或仍为 `error` |
| `hidden` | 快捷键 | 先显示窗口 → 然后自动触发开始录音（与 `idle` 下开始录音相同） | `recording`（窗口可见） |

### 2.2 长按模式（若用户在设置中开启）

| 当前状态 | 操作 | 系统响应 | 下一状态 |
|----------|------|----------|----------|
| `idle` | 按下按钮/快捷键 | 开始录音，按钮变红 | `recording` |
| `recording` | 松开按钮/快捷键 | 停止录音，进入识别等待 | `recognizing` |


### 2.3 VAD 自动停止（若启用）

| 当前状态 | 条件 | 系统响应 | 下一状态 |
|----------|------|----------|----------|
| `recording` | 检测到连续静音 ≥ 用户设定时长（如 1.2 秒） | 自动执行停止录音动作（同手动停止） | `recognizing` |

### 2.4 录音时长校验

- 任何方式停止录音后，计算总录音时长（毫秒）。
- 若 **< 500ms**：不调用 API，不清求识别，窗口文本框无变化，按钮恢复绿色，状态回到 `idle`，并短暂提示“说话时间太短”（非模态）。

### 2.5 流式识别过程（后台）

- 录音中，每个音频分片（例如每 0.5 秒）发送到 API。
- API 返回的每个中间结果（文字片段）：
  - 追加到**当前光标所在的输入框**（模拟键盘输入或直接修改 DOM 值）。
  - 同时追加到**窗口内部文本框**（实时显示）。
- 停止录音后，进入 `recognizing` 状态，等待最后 3~5 秒内的最终结果返回，追加后回到 `idle`。

### 2.6 识别错误处理

| 错误类型 | 系统响应 |
|----------|----------|
| API 返回错误码（4xx/5xx） | 立即停止录音（若还在录）→ 窗口文本框显示“识别中断”，不追加错误文字到光标输入框 → 回到 `idle` |
| 网络中断 / WebSocket 断开 | 同上，窗口文本框显示“网络中断，识别失败” |
| 超时（5 秒无响应） | 停止录音，提示“识别超时”，回到 `idle` |

## 3. 窗口与托盘交互

### 3.1 窗口操作

- 窗口本身**没有**最小化或关闭按钮（符合“无额外按键”要求）。
- 鼠标按住窗口空白区域拖动 → 移动窗口位置。

### 3.2 托盘交互

| 用户操作 | 响应 |
|----------|------|
| 右键托盘图标 | 弹出菜单，包含：**隐藏窗口**、**设置**、**关闭程序** |
| 左键托盘图标 | 如果窗口 `hidden` → 显示窗口；如果窗口已可见 → 无操作（或激活窗口） |
| 选择“隐藏窗口” | 窗口隐藏，状态变为 `hidden`，程序保留托盘图标 |
| 选择“关闭程序” | 完全退出程序（若正在录音先停止并丢弃音频） |
| 在 `hidden` 状态下按全局快捷键 | 先显示窗口，然后自动开始录音（等同于从 `idle` 开始录音） |

## 4. 设置面板交互

设置面板通过托盘右键菜单中的“设置”打开。其内部交互如下：

| 控件 | 用户操作 | 响应 |
|------|----------|------|
| 重新授权麦克风按钮 | 点击 | 重新请求系统麦克风权限，若同意则更新设备列表，若拒绝则保持禁用录音状态 |
| 长按/点按模式切换 | 点击开关 | 切换全局录音模式（点按 / 长按），立即生效 |
| 自定义快捷键输入框 | 用户按下组合键（如 `Ctrl+Shift+R`） | 记录新快捷键，点击“保存”后全局生效 |
| VAD 开关 | 开启/关闭 | 开启后，录音时自动检测静音；关闭后仅手动停止 |
| VAD 静音时长输入框 | 输入数字（如 `1.5`） | 校验为正数，保存后下次录音生效 |
| API 地址 / 密钥输入框 | 修改文本 | 保存后更新 API 调用配置 |
| 设置面板关闭 | 点击右上角关闭或点击外部 | 保存未保存的更改（或提示保存），关闭面板 |

## 5. 首次启动流程

1. 程序启动，窗口显示（黑色半透明卡片）。
2. 自动检测是否有麦克风权限：
   - 无 → 弹出系统权限请求弹窗。
   - 用户允许 → 正常进入 `idle`，按钮绿色。
   - 用户拒绝 → 进入 `error` 状态，按钮禁用或提示“无权限，请通过设置重新授权”。
3. 权限通过后，自动初始化音频上下文和 API 配置（使用默认或用户上次保存的）。

## 6. 状态与 UI 视觉映射

| 状态 | 麦克风按钮 | 内部文本框边框（可选） | 托盘图标（可选） |
|------|------------|------------------------|------------------|
| `idle` | 绿色迷你麦克风 | 正常 | 默认 |
| `recording` | 红色方块（或停止图标） | 闪烁或高亮 | 动态变化（红色点） |
| `recognizing` | 灰色或转圈 | 无特殊 | 等待图标 |
| `error` | 灰色 + 禁用 | 红色边框 | 红色叹号 |
| `hidden` | （窗口不可见） | — | 正常 |

## 7. 异常与边界情况处理

| 场景 | 处理方式 |
|------|----------|
| 录音中切换麦克风设备 | 忽略切换（或停止录音后再切），避免崩溃 |
| 录音中系统休眠 | 醒来后应检测到音频流中断，停止录音并提示“录音中断” |
| 用户快速连续单击开始/停止 | 防抖（例如 300ms 内忽略重复操作），避免频繁 API 调用 |
| 光标所在输入框为密码框或不可写 | 仅将结果写入窗口内部文本框，并提示“无法自动填入，请手动复制” |
| 窗口内部文本框内容过长 | 自动滚动到底部 |
