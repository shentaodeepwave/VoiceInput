# 语音输入法 - 交互逻辑

## 状态定义
- idle: 就绪
- recording: 录音中
- recognizing: 识别中
- error: 错误

## 操作与响应表

| 操作 | 当前状态 | 响应 | 下一状态 |
|------|----------|------|----------|
| 点按“右CTRL” | idle | 请求麦克风权限 → 开始采集 → 状态栏显示“录音中” | recording |
| 再次点按“右CTRL” | recording | 停止采集 → 状态栏显示“识别中” → 发送音频 | recognizing |
| VAD检测到静音持续超过阈值 | recording | 同点击“停止录音” | recognizing |
| 识别完成（成功） | recognizing | 文本框填入文字 → 状态栏“就绪” | idle |
| 识别失败（网络/API错误） | recognizing | 状态栏显示“错误”，保持原文本 | error（可重试） |
| 点击“复制” | 任意 | 文本框内容复制到剪贴板，短暂提示“已复制” | 状态不变 |
| 点击“清空” | 任意 | 清空文本框 | 状态不变 |
| 调节VAD滑块 | 任意 | 更新内部阈值，下次录音生效 | 状态不变 |
| 点击“重新授权” | 任意 | 重新请求麦克风权限，更新设备列表 | 状态不变 |
| 拖动窗口标题栏 | 任意 | 窗口移动 | 状态不变 |

## 异常处理
- 麦克风权限被拒绝：状态栏显示“错误：无麦克风权限”，不进行录音，提示去设置界面重新授权。
- 录音时长<0.5秒：忽略，状态栏提示“说话时间太短”
- 识别超时（5秒）：状态栏显示“错误：识别超时”，回到idle
