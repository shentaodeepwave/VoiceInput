# 竞品分析：讯飞流式 API + Windows EXE

## 一、竞品概览

| 产品 | 平台 | 中文准确率 | 实时性 | 主要问题 |
|------|------|------------|--------|----------|
| 讯飞听见 PC 版 | Windows | 98% | 低 | 侧重文件转写，非实时输入 |
| Wispr Flow | Mac / Windows | <50% | 高 | 中文识别不可用 |
| 豆包输入法 | 手机 / macOS | 92% | 高 | 无 Windows 版 |
| 微信输入法 | 手机 | 92% | 高 | 仅移动端 |
| Dragon NaturallySpeaking | Windows | 99% | 高 | 价格高，面向专业听写 |
| 阿里千问 PC 端 | Windows / Mac | 96% | 高 | 2026年5月刚上线，待验证 |
| 端侧 Whisper（自研） | 跨平台 | 92% | 高 | 术语错误多，需本地模型 |

## 二、关键结论

1. **没有现成产品能直接用**  
   - 手机输入法不能跨应用。  
   - Mac 产品（Wispr Flow、豆包）不覆盖 Windows 或中文差。  
   - 讯飞听见场景不匹配。  
   - Dragon 太贵。

2. **自研最优组合**  
   - **识别**：讯飞流式 WebAPI（中文准确率 98%+，流式延迟 <200ms，有 Windows SDK）  
   - **形态**：Windows EXE（支持全局快捷键、悬浮窗、跨应用文本注入）

3. **为什么不是其他 API**  
   - 百度、阿里、腾讯：准确率稍低（96-97%），或流式体验不如讯飞。  
   - 端侧 Whisper：准确率不足（92%），专业术语识别差。

## 三、总结

> 桌面端实时中文语音输入，现有成品要么平台不对、要么中文差、要么场景错位。自研选型中，讯飞流式 API + Windows EXE 是 72 小时内可交付、体验最优的方案。
