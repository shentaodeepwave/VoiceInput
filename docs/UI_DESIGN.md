# 语音输入法 - UI设计

## 整体风格
- 简约桌面风格（macOS 浅色）
- 无边框窗口，通过标题栏拖动
- 主色 #F5F5F7，按钮圆角 6px

## 布局（从顶到底）
1. 标题栏（高 40px）：左侧“语音输入法”，右侧 ⚙️ 图标 + ✖️ 图标
2. 状态栏（高 24px）：文字居中，字体 12px，灰色
3. 文本框（高 200px）：白色背景，灰色边框，内边距 12px，字体 16px
4. 按钮行（水平居中，间距 12px）：开始录音、停止录音、复制、清空
5. 底部（可选）：VAD 滑块条 + 数值

## 设置弹窗
- 宽 300px，背景白色，阴影
- 标题“设置”
- 麦克风设备下拉列表
- “重新授权”按钮
- VAD 延迟滑块（1.5/2.0/2.5，显示当前值）
- 关闭按钮

## 颜色
- 主按钮背景 #007AFF，文字白色
- 次按钮背景 #E5E5EA，文字黑色
- 错误状态文字 #FF3B30

## 字体
- SF Pro / Inter
