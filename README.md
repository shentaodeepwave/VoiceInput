## 📌 项目简介
本项目是一款**桌面语音输入工具**，帮助用户通过说话代替键盘打字，提升文本输入效率。  
我们专注于**高准确率、低成本、易用性**，在安静环境下识别准确率达 95%+，单次识别成本低于 0.002 元。

## ✨ 核心功能
- 🎤 **一键录音**：点击按钮开始/停止录音
- 📝 **实时转文字**：调用云端语音识别 API，秒级返回结果
- ✏️ **文本编辑**：支持手动修改、一键复制、清空
- 📊 **透明成本**：每次识别后显示预估费用（最低仅 0.0015 元/次）
- 🔄 **智能容灾**：主 API（讯飞）故障时自动切换备用 API（百度），保证演示不翻车
- ⚡ **可选 VAD**：静音自动断句，提升操作效率（如时间充裕则实现）
